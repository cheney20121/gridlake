# Gridlake 项目亮点

> **开源、可私有部署的亿级数据表格：像 Excel 一样用公式和透视表分析上亿行数据。**

本文介绍 Gridlake 的定位、亮点和与同类工具的区别，也附了可以直接用于推广的介绍文案。功能细节见 [用户手册](用户手册.md)，业务用法见 [应用场景](应用场景.md)，英文版见 [highlights.en.md](highlights.en.md)。

---

## 一句话

**Excel 的手感，数据库的容量。** 界面是 Excel 式的工作簿（基于 Univer），数据在服务端 DuckDB 里计算，浏览器只取看到的那一屏——1 亿行的表打开约 50 毫秒。

---

## 十个亮点

### 1. 亿级数据，像打开 Excel 一样快

实测 1 亿行 × 8 列（8 核 16 GB 笔记本，发布版）：

| 操作 | 耗时 |
|---|---|
| 打开整张表 | 52 毫秒 |
| 按店铺筛选（命中 33 万行） | 约 0.1 秒 |
| 透视：店铺 × 月份 | 1.8 秒 |
| SQL 分组汇总 | 0.5 秒 |
| 公式 `DSUMIFS`（两个条件） | 0.17 秒 |

慢的也写明了：冷启动全表排序 12 ~ 18 秒、1 亿唯一值精确去重 17 ~ 44 秒。压测方法开源，可以自己复现。

### 2. 不用学新东西：公式、透视表、图表都是 Excel 的样子

- 普通单元格就是电子表格：几百个 Excel 函数、条件格式、行列分组、命名区域，xlsx 导入导出；
- 引用大数据集的公式（`SUMIFS(订单表[金额], …)`、`DSUMIFS`）自动**下推到服务端**计算，导出时转回 Excel 原生公式；
- 透视表支持计算值、计算项、同比 / 环比、近似分位数，**每个格子双击下钻到明细并自动核对**。

### 3. 数据表上的「Excel 功能」都做到了千万行

汇总行、**分类汇总（可折叠）**、数据概况（直方图 + 常见值）、筛选、排序、搜索、选区统计、拆分 / 合并列、计算列、关联（类似 VLOOKUP）——全部在服务端整表计算，不是只算屏幕上的几百行。

### 4. 数据质量一条龙：体检 → 校验 → 清洗

- **数据概况**一次扫描看出每列的空值、异常日期、取值分布；
- **校验规则**（必填、唯一、范围、手机号 / 邮箱 / 正则、取值列表）在导入、同步后自动检查，一键只看不合格的行，失败时发 Webhook；
- **数据清洗**（去重、去空白、统一写法、补空值、删除行）先预览改前改后，**可以撤销**。

### 5. 让数据自己动起来

数据连接（MySQL / PG、ClickHouse、HTTP、S3、文件夹）定时同步 → SQL 派生数据集「源数据更新后」自动重算 → 定时推送到企业微信 / 钉钉 / 飞书 / 邮件 → 阈值告警（比率、环比变化、数据停更）→ 事件 Webhook 通知外部系统。整条链路不用写代码。

### 6. 多人协作，不再合并几十个 Excel

实时协作、评论 @、版本历史、文件审批；**收集任务**让几十家门店往同一个数据集里各填各的，看板上看谁没交、一键催办、审核退回。

### 7. 安全可控的 AI 助手

- 接你自己的 OpenAI 兼容模型（可以是私有部署的）；
- 回答里的每个数字都来自查询工具，可追溯；
- 会改数据的操作（建透视表、加计算列、清洗、生成数据集）只给**建议卡片**，看过预览、点「应用」才执行，**可撤销**；
- 在数据集页面提问时，自动知道你正在看哪张表、哪些筛选条件；
- 对外提供 **MCP** 只读接口，Claude Desktop、Cursor 等外部 AI 按令牌权限查询。

### 8. 企业级权限与治理

内置账号 + OIDC 单点登录、网关 / 反向代理登录；**按店铺 / 地区 / 部门的行级权限**（透视、公式、SQL、导出、AI 统一生效，白名单式设计）；操作审计；个人访问令牌（可只读、限定数据集）；只读分享链接（密码、有效期、可吊销）。

### 9. 部署极简，数据不出门

- 一个二进制 + 一个数据文件，Docker 一条命令；
- `gridlake demo` 几秒生成 100 万行示例和三个做好的工作簿；
- `gridlake open 文件.parquet` 在本机直接用表格打开大文件；
- 备份恢复、恢复演练、Prometheus 指标、慢请求日志一应俱全。

### 10. 认真的工程质量

| 项目 | 数量 |
|---|---|
| 后端（Rust） | 约 4.8 万行 |
| 前端（Vue 3 + TypeScript） | 约 5.3 万行 |
| 后端单元测试 | 264 个 |
| 后端端到端测试 | 68 个测试文件（每个起一个独立的服务） |
| 前端单元测试 | 253 个 |
| 浏览器界面测试 | 22 个测试文件、92 个用例 |
| 界面英文翻译 | 约 3270 条 |

CI 跑全部测试、依赖许可证检查、敏感内容检查；SQL 只读白名单（用 DuckDB 自己的解析器检查）、密钥 AES-GCM 加密、令牌只存摘要、用户输入一律参数化。

| | Excel | BI 工具 | 数据库式表格（Airtable 类） | Jupyter / Python | **Gridlake** |

| 透视表 | ✅ | ✅ | 部分 | 要写代码 | ✅ **可下钻核对** |
| 固定看板、定时推送 | ❌ | ✅ | 部分 | ❌ | ✅ |
| 多人填报收集 | 靠邮件 | ❌ | ✅ | ❌ | ✅ |
| 数据质量校验 / 清洗 | 手工 | 部分 | 部分 | 要写代码 | ✅ **可预览可撤销** |
| 行级权限 | ❌ | ✅ | 部分 | ❌ | ✅ |

## 技术亮点（给开发者）

- **Rust + axum + DuckDB**：单个进程，内嵌列式分析引擎；Parquet 直接查询不复制。
- **画布表格 + 游标**：前端用 canvas 绘制、按可视区域分段取数；服务端为每个「筛选 + 排序」建位置表并缓存，无筛选时用「直通游标」（行号即位置，1 亿行不建任何中间表）。
- **一切下推**：透视（GROUPING SETS）、公式（按条件签名批量合并成一条 SQL）、汇总行、分类汇总、数据概况、校验，都翻译成参数化 SQL 在服务端算。
- **分类汇总不复制数据**：服务端只返回每组的行数和汇总，前端用前缀和 + 二分查找在「显示行」和数据行之间换算，折叠的组不取数。
- **计算列是表达式**：Excel 风格公式安全翻译成 SQL（不拼接用户输入），在筛选、透视、公式里就地展开；拆分 / 合并列也是计算列，新数据自动适用。
- **可撤销的数据修改**：清洗前把要删的行、要改的原值存到撤销区，按数据版本和列结构判断还能不能撤销。
- **AI 工具的边界**：查询类工具直接执行；产出类工具只生成建议（带服务端预览），由前端调用与手动操作相同的接口执行，权限检查一致。
- **测试驱动的权限**：受限用户能调用的接口是白名单，单元测试强制每条路由都已分类。

## 推广文案（可直接使用）

### 一句话（标题、简介栏）

> Gridlake：开源的亿级数据表格，像 Excel 一样用公式和透视表分析上亿行数据。

### 短介绍（约 100 字，适合仓库简介、群公告）

> Gridlake 是一个开源、可私有部署的数据表格：界面和 Excel 一样，可以写公式、拖透视表、做图表和仪表盘；数据放在服务端 DuckDB 里，1 亿行打开约 50 毫秒。还带数据校验与清洗、定时推送、阈值告警、多人填报、行级权限和可撤销的 AI 助手。Apache-2.0 开源，一条命令就能体验。

### 长介绍（适合文章、发布帖）

> 很多团队都遇到过这个尴尬：数据一过百万行，Excel 就打不开了；BI 工具做固定看板很好，可业务想临时改个口径、加一列算毛利，又得找人排期。
>
> Gridlake 想把两边的好处放在一起：**界面是 Excel 式的工作簿**，公式、透视表、图表、条件格式都是熟悉的样子；**数据放在服务端的 DuckDB 里**，浏览器只取看到的那一屏。实测 1 亿行的订单表打开只要 52 毫秒，按店铺筛选 0.1 秒，透视 1.8 秒。
>
> 围绕「数据太大、需求太灵活」，它还做了一整套能力：千万行上的汇总行和可折叠的分类汇总；数据概况、校验规则和可撤销的数据清洗；数据连接定时同步、SQL 派生数据集自动重算、定时推送和阈值告警；几十家门店一起填报的收集任务；按店铺 / 部门的行级权限和操作审计；以及一个所有改动都要你确认、可以撤销的 AI 助手。
>
> 项目用 Rust + DuckDB + Vue 3 + Univer 编写，Apache-2.0 开源，单机即可部署，数据不出你的服务器。下载后运行 `gridlake demo`，几秒就能看到 100 万行的示例和做好的报表。

### 演示脚本（5 分钟）

1. `gridlake demo`，打开「月度经营分析」：点切片器换店铺和月份，指标卡和图表联动（1 分钟）；
2. 打开 100 万行的「订单」数据集：滚动、筛选、搜索，状态栏选区统计；打开「Σ 汇总行」，按店铺「分类汇总」，再「全部折叠」（1 分钟）；
3. 「透视分析」：渠道 × 月份，值显示环比；双击一个格子下钻，看自动核对（1 分钟）；
4. 「数据概况」看每列的分布，「数据校验」加一条「手机号格式」，「只看这些行」（1 分钟）；
5. 打开 AI 助手问「本月销售额比上月变化了多少，主要是哪些店铺？」，再让它生成透视表方案卡，应用、撤销（1 分钟）。

```bash
# 或者 Docker
docker compose -f deploy/docker-compose.yml up -d
```
