## 1. 基本概念

| 名称 | 是什么 | 打个比方 |
|---|---|---|
| **工作簿** | 和 Excel 文件一样的表格：多个工作表、公式、样式、图表 | 一个 .xlsx 文件 |
| **数据集** | 放在服务端的一张大表（可以上亿行），浏览器只取看到的那一屏 | 一张数据库表，但不用写 SQL 就能用 |
| **数据表** | 打开一个数据集看到的表格界面：筛选、排序、搜索、汇总都在服务端算 | 装得下上亿行的「筛选视图」 |
| **计算列** | 用公式在数据集上加出来的列，不改原始数据，新导入的行自动算好 | Excel 表格里的公式列 |
| **关联视图** | 按键把两个数据集拼在一起（类似 VLOOKUP / JOIN），不复制数据 | 一张「虚拟」的合并表 |
| **场景包** | 可选的行业功能（目前有电商资金台账），默认不开启 | 插件 |

**大数据集和普通单元格的分工**：几千、几万行的手工表格直接放在工作表的单元格里；几十万到上亿行的明细放成数据集，在工作表里用透视表、公式（`DSUMIFS` 等）、数据表引用它，计算都在服务端完成。

## 2. 第一次使用

### 2.1 只想先看看效果

下载发布包解压后运行：

```bash
bin/gridlake demo
```

几秒后浏览器自动打开，里面有 100 万行订单、库存流水、往来明细，以及做好的三个工作簿：月度经营分析、库存进销存、应收应付对账。可以随便点切片器、看透视表、写公式，演示库和正式数据完全分开。

### 2.2 在自己电脑上打开一个文件

```bash
bin/gridlake open 订单.parquet 客户.csv
bin/gridlake open /data/orders/          # 整个目录的 Parquet
```

Parquet 直接查询、不复制；CSV / XLSX / JSON 会导入。只监听本机，不需要登录。

### 2.3 团队使用

由管理员按 [部署手册](../deploy/部署手册.md) 部署后，用浏览器打开 `http://服务器地址:8787/excel`，用管理员给的账号登录。

### 2.4 首页一览

| 首页左侧 | 能做什么 |
|---|---|
| **最近** | 最近打开的工作簿；搜索、加星标、按所有者 / 修改时间排序 |
| **已加星标** | 加了星标的工作簿 |
| **数据中心** | 导入数据、SQL 查询、数据连接、数据集列表、回收站 |
| **自动化** | 定时推送、收集任务、我的填报、阈值告警、数据同步；管理员还有外部 AI 接入（MCP）、事件 Webhook、数据权限、账号管理、操作审计 |
| **模板库** | 从内置或团队发布的模板新建工作簿 |

## 3. 把数据放进来

### 3.1 导入文件

**数据中心 → 导入数据**（或在工作簿里「分析 → 导入数据集」）：

1. 选择文件（CSV、XLSX、Parquet、JSON，可一次多个），或者粘贴一个下载链接。
2. 预览：系统自动识别编码、表头和每列的类型（文本、编号、整数、数值、金额、日期时间、是/否），每列给出填充率和样例；类型不对可以直接改。
3. 选择写入方式：
   - **新建**：建一个新的数据集；
   - **追加**：加到已有数据集末尾（按列名对齐，同一来源的文件会记住列的对应关系）；
   - **整体替换**：清空后重新写入；
   - **按主键更新**：主键相同的行覆盖，新的追加（适合每天导一份「最近 7 天」的增量）。
4. 提交。千万行的文件也是流式导入，不会卡住浏览器。

> 小贴士：订单号、手机号（11 位、1 开头）、身份证号（末位可以是 X）、以 0 开头的编号会被识别成「编号」，按文本保存，不会变成科学计数法、显示成 13,800,138,000 或丢失前导零；列名是工号、邮编、会员编号、卡号这类、值都是纯数字的列也按编号。「序号」「数量」仍是数字（要按大小排序、能求和）。

### 3.2 外部文件：不导入、直接查询

数据放在服务器目录或对象存储里的 Parquet 文件，可以建成**外部数据集**：数据不复制，打开就能浏览、透视、写公式；可设置「每 N 分钟自动检查文件变化」，有新文件自动刷新。在数据表上点「设置…」修改读取方式。

### 3.3 数据连接：定时同步

**数据中心 → 数据连接**：接入 MySQL / PostgreSQL、ClickHouse、HTTP 接口（支持分页、增量）、文件夹、S3 及兼容对象存储。设置同步计划后自动拉取，密钥加密保存；失败会在首页和命令面板里提示。

### 3.4 数据集管理

- 左侧「数据」面板列出所有数据集，点开即是数据表。
- 数据集名称旁的下拉菜单可以改名、查看**使用情况**（哪些工作簿、模板、SQL、推送用到了它）、删除。
- 删除的数据集进入**回收站**，可恢复。

## 4. 浏览大数据表

打开数据集后看到的就是数据表。上亿行也只取当前屏幕的数据，滚动、筛选、排序都在服务端完成。

| 操作 | 做法 |
|---|---|
| 筛选 | 点列头右侧的按钮：按取值勾选（显示每个值的行数）、按区间、包含、开头是… 筛选条件显示成标签，点 × 去掉 |
| 排序 | 同一个列头菜单里选升序 / 降序 |
| 关键字搜索 | 工具栏的搜索框，搜所有文本列 |
| 看一行的全部字段 | 双击该行 |
| 跳到第 N 行 | Ctrl + G，或状态栏「跳转到行」 |
| 选区统计 | 拖选多个格子，状态栏显示计数、求和、平均、最小、最大（按服务端数据算，不受屏幕限制） |
| 复制 | Ctrl + C，可直接粘贴到 Excel（一次最多 2 万行，更多请导出） |
| 调整列宽 | 拖列头边缘；双击自动适配 |
| 导出 | 工具栏「导出 ▾」：Excel（含汇总页签）或 CSV（最多 100 万行），按当前筛选和排序 |
| 放进工作表 | 「放入工作表」：把当前筛选的明细作为一张数据表放进工作簿 |

## 5. 汇总：汇总行、分类汇总、数据概况

### 5.1 汇总行

点状态栏右侧的「**Σ 汇总行**」，表格底部固定一行汇总，**按当前筛选的全部行**计算（不是只算屏幕上的）。

- 点某一列的汇总格选择方式：数值列可选合计、平均、中位数、最小、最大；日期列最早 / 最晚；是/否列数「是」；所有列都能数非空、空值、不同值；也可以「不汇总」。
- 数值列默认合计；看起来是编号的列（单号、编号、ID）默认不汇总。
- 开关和每列的选择记在本机浏览器。

### 5.2 分类汇总

在某列的列头菜单里选「**按此列分类汇总**」：数据按这一列排好，每组最后一行后面插一行小计（如「北京店 小计（3 行）」），小计方式与汇总行一致。

- 点小计行的行号（▾ / ▸）或双击小计行，**折叠 / 展开**这一组；工具栏的「全部折叠」只看各组小计，相当于一张按组汇总的表。
- 可以和筛选、搜索、「只看不合格」一起用；小计行不占行号，选区统计和复制都只算数据行。
- **多级分类汇总**：已经按「店铺」分类汇总时，在「渠道」列的列头菜单选「**添加为第 2 级分类汇总**」，每个店铺里再按渠道分组：先是各渠道的小计，再是店铺的小计（颜色深一些），最多 3 级。工具栏「折叠到 店铺 / 渠道」一键只看到某一级的小计；在某一级的列头菜单里可以「取消这一级」，标签上的 × 全部取消。
- 取值超过 1 万种的列（或几级的组合超过 1 万种）不能分类汇总，请先筛选或换一列。
- 分类汇总时「导出 ▾ → Excel」：每组后面带小计行（`SUBTOTAL` 公式）、最后一行总计，并设成 Excel 的分级显示，在 Excel 左侧点 1 / 2（两级时 1 / 2 / 3）折叠或展开；界面上折叠的组导出后也是折叠的。

### 5.3 数据概况

工具栏「**数据概况**」：一次扫描看清每一列——空值多少、几种不同的值、最小 / 最大、平均 / 中位数、认不出的日期写法。点开一列看直方图和最常见的取值，点其中一档就按它筛选。适合拿到一份新数据时先「体检」。

## 6. 整理数据：列类型、计算列、拆分合并、清洗、校验

### 6.1 修改列类型

列头菜单「更改列类型」：先预览有多少个值转不过来、举例，再确认。例如把被识别成数值的订单号改成「编号」、把文本日期改成「日期时间」。

### 6.2 计算列

「更多 → 计算列…」，用公式新增一列，例如：

```
=[订单金额]-[成本]*[数量]
=IF([方向]="入账",[金额],-[金额])
=LEFT([下单时间],7)                      // 取月份
=ROUND([毛利]/[订单金额],4)
```

可用函数：ROUND ABS IF IFNULL MAX MIN LEFT RIGHT MID LEN UPPER LOWER TRIM YEAR MONTH DAY，以及拆分 / 合并文本用的 FIND SUBSTITUTE SPLITPART TEXTBEFORE TEXTAFTER CONCAT TEXTJOIN。计算列可以被筛选、透视、公式引用；不需要了在列头菜单删除。

### 6.3 拆分 / 合并列

「更多 → 拆分 / 合并列…」：

- **拆分一列**：选列和分隔符（`-` `/` `,` 空格等，也可以自己输入），先预览每行能拆成几段（如「1 段 1 行，3 段 3 行，空 1 行」）和样例，列数默认取最常见的段数，填好新列名（省 / 市 / 区）。可选「最后一列保留剩下的全部」「去掉首尾空白」。
- **合并几列**：按选择的先后顺序拼接，可设分隔符、跳过空值。

结果是计算列，原始数据不变，以后新导入的行也会自动拆好。

### 6.4 关联（类似 VLOOKUP）

「更多 → 关联…」：按键把另一个数据集的列带进来（如订单按商品编码带入成本价），生成关联视图，不复制数据。

### 6.5 数据清洗

「更多 → 数据清洗…」（数据集的所有者或管理员）：

| 清洗 | 用途 |
|---|---|
| 删除重复行 | 按全部列或选定的列判断，保留最先导入的一行 |
| 去首尾空白 | 包括全角空格；只有空白的格子变成空值 |
| 查找替换 | 整格等于（统一「北京」「北京市」）或包含（替换每一处） |
| 填充空值 | 填固定值，或用上一行的值向下填充 |
| 删除筛选出的行 | 先在数据表上筛选出要删的行（必须有筛选条件） |

每次都先预览受影响的行数和改前 / 改后样例，删除行会再确认一次；**最近一次清洗可以撤销**（之后数据又有变化时不能撤销，会说明原因）。

### 6.6 数据校验规则

「更多 → 数据校验…」给列设规则：

| 规则 | 例子 |
|---|---|
| 必填 | 手机号不能为空 |
| 不能重复 | 订单号唯一 |
| 取值范围 | 金额 0 ~ 100000；下单时间 2026-01-01 ~ 2026-12-31 |
| 格式 | 手机号、邮箱、日期、纯数字、身份证号，或自定义正则（如 `SKU-\d+`） |
| 只能是 | 会员等级只能是 金卡 / 银卡 / 铜卡 |

不知道该设什么规则时点「**推荐规则**」：按数据本身的样子推荐，每条写明原因和现在有几行不合格，例如：

- 9 成以上的值是手机号 / 邮箱 / 身份证号格式 → 「是手机号格式」（剩下的那几个多半是录错了）；
- 列名像编号（单号、编号、ID…）且几乎不重复 → 「不能重复」「必填」；
- 差不多都填了、只空了几行 → 「必填」；
- 取值只有几种的文本列 → 「只能是 金卡 / 银卡 / 普通」，只出现过一两次的写法（如「钻石」）不放进去，并点出来；
- 金额、数量这类列没有负数或只有个别负数 → 「不小于 0」。

勾选要的，点「添加选中的 N 条」加进列表，保存后才生效；已经有的规则不会再推荐。不用配置 AI 也能用。

点「保存并检查」后列出每条规则不合格的行数和举例。之后**每次导入、同步、清洗后自动重新检查**，数据表上方显示「校验：2 项不通过（3 行）」。点某条规则的「只看这些行」把不合格的行筛出来，可以导出给相关人员修改，或交给「数据清洗 → 删除筛选出的行」处理。管理员可以订阅 `dataset.validation_failed` 事件，校验失败时自动通知。

## 7. 透视表与图表

### 7.1 透视表

数据表工具栏「**透视分析**」（以当前筛选为范围），或在工作簿里「分析 → 数据透视表」：

1. 选数据集，拖字段到行、列、值；日期字段可以按年 / 季 / 月 / 周 / 日分组。
2. 值的汇总方式：求和、计数、平均、最大最小、首个 / 末个、去重计数（精确或近似）、中位数、分位数等；显示方式：原值、占总计 / 行 / 列、同比、环比。
3. **计算值**：用公式组合已有的值，如毛利率 `([金额（求和）]-[成本（求和）])/[金额（求和）]`。
4. **计算项**：在某个字段的取值之间运算，如「期末 = 期初 + 入库 - 出库」。
5. 结果写成普通工作表，可以继续写公式、做图表；**双击任一格子下钻**到明细，并自动核对明细合计是否等于这个格子。
6. 「转为数据表」后可以按值再筛选。

### 7.2 图表

数据表工具栏「图表分析」，或「分析 → 图表」：柱形、条形、折线、面积、饼图、环形、瀑布图。基于数据集的图表在服务端汇总，数据更新后自动刷新；可以和切片器联动。

## 8. 在工作表里用大数据：公式与数据表

### 8.1 平台函数（在服务端计算）

```
=DSUMIFS("订单", "金额", "店铺", B2, "下单时间", ">=2026-09-01")
=DCOUNTIFS("订单", "状态", "已退款")
=DAVERAGEIFS / DMAXIFS / DMINIFS（用法同 DSUMIFS）
=DCOUNTDISTINCTIFS("订单", "用户ID", "店铺", B2)
=DLOOKUP("商品", "成本价", "商品编码", A2)
```

也可以写成 Excel 的表格引用：`=SUMIFS(订单表[金额], 订单表[店铺], B2)`，引用大数据集时同样下推到服务端。导出 xlsx 时会转回 Excel 原生公式。完整说明见 [公式与 Excel 兼容](formulas.md)，逐个函数的支持情况见 [Excel 函数兼容清单](excel-functions.md)。

### 8.2 数据表嵌入工作表

把数据集的明细放进工作表（数据表上的「放入工作表」），可选**浮动表格**（内部滚动，千万行也只取可视区域）或**写成单元格**（不超过 1 万行，可以用 `A:A` 这类引用）。数据表随数据集和切片器刷新，可以设置列的数字格式（万元、百分比）和条件格式（超过阈值标红）。

### 8.3 公式诊断

「分析 → 公式诊断」：找出拖慢计算的公式（整列引用、易失函数、大量查找），并给出改法。

## 9. SQL 查询与窗口计算

### 9.1 SQL 查询

数据中心 → SQL 查询（或「分析 → SQL 查询」）：

- 表名就是数据集名称，列名就是中文列名，只允许 SELECT / WITH（只读）。
- 支持参数（按类型安全代入）。
- 结果可以**另存为数据集**，并设置重算计划：手动、定时，或「**源数据集更新后**」自动重算。
- 单元格里也能写 `=SQLVALUE("SELECT …")` 取一个值。

### 9.2 窗口计算（不写 SQL）

数据表「更多 → 窗口计算…」：按分组和组内顺序算累计、序号、排名、上一行的值、与上一行的差、变化率、移动平均、组内合计 / 平均 / 行数、占组内比例，可选「每组只保留前 N 行」（如每家店铺销售额最高的 10 天）。先预览前 100 行，再生成新数据集；源数据更新后自动重算。

## 10. 仪表盘与演示

「分析 → 仪表盘」（或「插入 → 看板部件」）在工作表上放：

- **切片器**：按取值或日期区间筛选，可以跨数据集联动；
- **指标卡**：一个数字加同比 / 环比；
- **表格卡片**：排行榜、明细 Top N；
- **图表**。

「分析 → 演示」全屏只读展示当前工作表，切片器和图表联动照常可用，适合开会投屏。

## 11. AI 助手

点顶部「✦ AI 助手」（需要管理员配置 OpenAI 兼容的模型），用中文提问：

| 你可以问 | 助手会做 |
|---|---|
| 本月销售额比上月变化了多少？主要是哪些店铺造成的？ | 两期对比归因，结论里的数字都来自查询 |
| 最近有什么异常？ | 扫描最近 7 天相对此前 28 天的骤降、骤升 |
| 这张表的数据有没有问题？帮我清理一下 | 数据体检，再给出清洗建议（看过改前改后才执行） |
| 各店铺今年每月的销售额，做成透视表并配一张趋势图 | 生成「方案卡」，预览后一次应用、一次撤销 |
| 每家店铺销售额最高的 10 天，生成一个数据集 | 窗口计算建议 |
| 把收货地址拆成省、市、区 | 计算列建议 |
| 帮这张表设校验规则，以后导入时自动检查 | 按数据推荐校验规则（也可以说清楚要什么规则），卡片上列出每条现在有几行不合格；应用后保存，可撤销 |

要点：

- 所有会改动工作簿或数据的操作都只生成**建议卡片**，你点「应用」才执行，应用后可以撤销。
- 在数据集页面提问时，助手自动知道你正在看哪个数据集、当前的筛选（面板底部会显示「数据集「订单」· 当前筛选（2 行）」），说「这些订单」就够了。
- 数据范围受限的用户，助手也只能看到他能看到的数据。

## 12. 自动化：推送、告警、填报、Webhook

### 12.1 定时推送

自动化 → 定时推送：把某个仪表盘页按日 / 周 / 月（或数据更新后）发到企业微信、钉钉、飞书或邮件，内容是当时算出的指标和表格。

### 12.2 阈值告警

自动化 → 阈值告警：指标（或两个汇总值的比率，如退款率）按分组超过阈值时通知。支持：

- 和上期比的变化（「销售额较上周下降 30%」）；
- 数据停更（「哪家店铺 3 天没有新订单」）；
- 样本量保护（订单太少时不报）；
- 同一个问题只在新出现时通知，恢复时可通知；保存前可以「试算」看看现在会不会触发。

### 12.3 多人填报（收集任务）

自动化 → 收集任务：让几十家店铺 / 部门往同一个数据集里各填各的。

1. 「+ 新建收集任务」：起个名字（如「月度经营数据」），设置填报表要填的列、**单位列**（区分不同行，如店铺）和**期次列**（如 2026-10、2026-W42），添加填报单位并指定负责人。
2. 「开启新一期」并设截止日期；负责人在「我的填报」里只看到、只能填自己的单位（自动同步成数据权限），可以批量粘贴。
3. 看板上看每个单位的状态（待填、已提交、已确认、已退回），对没交的「催办」（推送到群），对交上来的「审核」确认或退回；也能「复制未提交名单」。

工作簿里也可以放「填报区」（分析 → 填报），在表格里填好后提交写入数据集，可撤销。

### 12.4 事件 Webhook（管理员）

自动化 → 事件 Webhook：在导入、同步、填报、审批、告警、校验失败等事件发生时，向外部系统发送签名的 HTTP 请求（数据管道、工单系统、自己的脚本），失败自动重试，可以查看每次发送的记录、手动重发。

## 13. 协作、分享与版本

- **实时协作**：多人同时编辑一个工作簿，看到彼此的光标。
- **评论与 @**：选中格子写评论，@ 同事会收到通知（右上角铃铛）。
- **版本历史**：「分析 → 版本历史」查看并恢复以前的版本。
- **分享链接**：右上角「分享链接…」（或 Alt+Q 搜「分享」），给没有账号的客户 / 合作方一个只读链接：能看工作簿里的图表、指标卡、切片器的实时数据，不能编辑、不能导出；数据范围不超过创建人；可设访问密码、有效期，随时吊销。
- **文件审批**：右上角「审批 ▾ → 发起审批」，审批人在「审批中心」处理。
- **模板**：「发布为模板」把做好的工作簿（可带参数，如选数据集、选月份）分享给团队，别人「从模板新建」即可复用。
- **xlsx 导入导出**：Alt+Q 搜「导入 Excel」「导出为 Excel」；条件格式、表格、行列分组、命名区域、平台函数都会尽量保留或转换。

## 15. 常见问题

**Q：能放多少行？**
单机 DuckDB，实测 1 亿行 × 8 列打开整张表约 50 毫秒、按店铺筛选约 0.1 秒、透视约 2 秒（详见 README 的性能表）。更大规模受服务器内存和磁盘影响。

**Q：和 Excel 公式兼容吗？**
普通单元格里的公式由 Univer 计算，常用函数基本都支持；逐个函数的情况见 [Excel 函数兼容清单](excel-functions.md)。引用大数据集的公式改用平台函数（DSUMIFS 等）或表格引用，在服务端计算。

**Q：清洗删错了怎么办？**
最近一次清洗可以在「数据清洗」对话框里撤销；更早的改动请从备份恢复。删除的数据集在回收站里。

**Q：为什么有些菜单我看不到？**
可能是权限：数据清洗、改校验规则需要是数据集所有者或管理员；数据范围受限的用户不能生成新数据集、不能发分享链接；管理员功能（账号、审计、Webhook、MCP）只有管理员可见。

**Q：界面能切换成英文吗？**
可以，右上角语言切换。绝大部分界面和报错已翻译，电商台账场景包和部分提示仍是中文。
