# 公式：平台函数与 Excel 兼容

Gridlake 的公式引擎是 Univer（浏览器里计算，函数集与 Excel 基本对应）。普通工作表的公式照常在浏览器里算；
**引用大数据集的公式用平台函数，下推到服务端 DuckDB 计算**，浏览器只拿到一个数。

## 数据集函数（D 系列）

对「数据中心」里的数据集（可到上亿行）按条件汇总。参数与 Excel 的 `SUMIFS` 一致，只是「区域」换成「数据集名 + 列名」。

| 函数 | 写法 | 说明 |
|---|---|---|
| `DSUMIFS` | `DSUMIFS(数据集, 求和列, 条件列1, 条件1, …)` | 按多个条件求和 |
| `DCOUNTIFS` | `DCOUNTIFS(数据集, 条件列1, 条件1, …)` | 按多个条件计数 |
| `DAVERAGEIFS` | `DAVERAGEIFS(数据集, 平均列, 条件列1, 条件1, …)` | 按多个条件求平均 |
| `DMAXIFS` | `DMAXIFS(数据集, 取值列, 条件列1, 条件1, …)` | 按多个条件取最大值；没有符合条件的数值时为 0（同 Excel 的 `MAXIFS`） |
| `DMINIFS` | `DMINIFS(数据集, 取值列, 条件列1, 条件1, …)` | 按多个条件取最小值；同上 |
| `DCOUNTDISTINCTIFS` | `DCOUNTDISTINCTIFS(数据集, 去重列, 条件列1, 条件1, …)` | 按多个条件统计**不重复的取值个数**（如某店铺有多少个不同的客户）。空值不算一个取值，取值区分大小写，去重列可以是文本或数值列；多个分组之间也会正确去重（不是各组个数相加） |
| `DLOOKUP` | `DLOOKUP(数据集, 返回列, 条件列1, 条件1, …)` | 数据集版 VLOOKUP：返回**第一条**匹配行的值，找不到为 `#N/A` |

```
=DSUMIFS("订单", "金额", "店铺", B2, "状态", "已完成")
=DCOUNTIFS("订单", "状态", "已退款")
=DAVERAGEIFS("订单", "金额", "渠道", "直播")
=DMAXIFS("订单", "金额", "店铺", B2)
=DCOUNTDISTINCTIFS("订单", "客户", "店铺", B2)
=DLOOKUP("商品成本", "成本价", "商品ID", A2)
```

**条件写法**：支持比较运算 `>` `<` `=` `<>`（如 `">=2026-01-01"`、`"<0"`）和通配符 `*`（任意多个字符）`?`（一个字符）`~`（转义），与 Excel 一致。数据集名、列名写成字符串。

## 在单元格里写 SQL（SQL / SQLVALUE）

对数据集执行**只读** SQL（DuckDB 方言，与 SQL 工作台同一套检查与时限），结果放进工作表：

| 函数 | 写法 | 说明 |
|---|---|---|
| `SQL` | `SQL(查询, 参数名1, 值1, …)` | 结果**带表头**铺到右下方（动态数组，像 FILTER 一样溢出），最多 1000 行，超过时报错（请先 `GROUP BY` 汇总或加 `LIMIT`） |
| `SQLVALUE` | `SQLVALUE(查询, 参数名1, 值1, …)` | 只取第一行第一列，适合指标；没有行时为 `#N/A` |

```
=SQL("SELECT 店铺, sum(金额) AS 金额 FROM 订单 GROUP BY 1 ORDER BY 2 DESC")
=SQLVALUE("SELECT sum(金额) FROM 订单 WHERE 店铺 = {{店铺}} AND 下单时间 >= {{起}}", "店铺", B2, "起", TEXT(C1, "yyyy-mm-dd"))
```

- 表名就是数据集名称，列名是中文列名（含空格或符号时加双引号）；日期时间列是文本（如 `2026-09-15 10:00:00`），按月分组用 `left(列, 7)`。
- 参数：查询后面跟「参数名, 值」对，代入 SQL 里的 `{{参数名}}`。值是数字的按数字代入，其他按文本代入（加引号、转义，**不会拼成 SQL**）；日期单元格在表格里是序号，请用 `TEXT(单元格, "yyyy-mm-dd")` 转成文本。
- 计算方式与 D 系列相同：第一遍先显示「计算中…」，查询在服务端并发执行（最多 4 个），结果缓存，导入 / 删除数据集后自动重算；查询或参数单元格变了才重新查询。
- 只读：只能 `SELECT` / `WITH`，改数据、建表、读文件的语句一律拒绝，出错时单元格显示原因（如 `#没有数据集「…」`）。数据权限受限的用户只查得到自己范围内的行。
- **分享链接**：访客打开的工作簿里有 SQL 公式时照常计算，但访客只能查这个工作簿用到的数据集（含 SQL 公式里写到的），在创建人的数据范围内执行。
- 导出 xlsx 时与其他平台函数一样写入计算结果（含铺开的整块区域），原公式记在批注里。用模板时 SQL 里的数据集名**不会**自动替换（发布模板时会提示）。

## 数据表函数（T 系列）

工作表里的「数据表」（嵌入工作表的浮动表格或单元格表格）按**表名**引用，按数据表**当前显示的行**（它的筛选、搜索、切片器）计算。

| 函数 | 写法 | 说明 |
|---|---|---|
| `TSUM` | `TSUM("表名[列名]", 条件列1, 条件1, …)` | 求和 |
| `TCOUNT` | `TCOUNT("表名", 条件列1, 条件1, …)` | 行数 / 按条件计数 |
| `TAVERAGE` | `TAVERAGE("表名[列名]", …)` | 平均值 |
| `TMIN` / `TMAX` | `TMIN("表名[列名]", …)` | 最小 / 最大值 |
| `TVALUE` | `TVALUE("表名[列名]", N)` | 当前排序下第 N 行的值 |

### 直接写 Excel 的表格引用

输入公式时可以按 Excel 习惯写，提交后自动转成上面的函数；**导出 xlsx 时再转回** Excel 原生公式，在 Excel 里照样能算：

| 你输入 | 存成 | 导出 xlsx 时 |
|---|---|---|
| `=SUM(订单表[金额])` | `=TSUM("订单表[金额]")` | `=SUM(订单表[金额])` |
| `=SUMIFS(订单表[金额], 订单表[店铺], B2)` | `=TSUM("订单表[金额]", "店铺", B2)` | `=SUMIFS(订单表[金额], 订单表[店铺], B2)` |
| `=AVERAGEIFS(订单表[金额], 订单表[店铺], B2)` | `=TAVERAGE("订单表[金额]", "店铺", B2)` | 同左 |
| `=COUNTIFS(订单表[店铺], B2)` | `=TCOUNT("订单表", "店铺", B2)` | 同左 |
| `=COUNTIF(订单表[店铺], "A店")` | `=TCOUNT("订单表", "店铺", "A店")` | 同左 |
| `=SUMIF(订单表[店铺], B2, 订单表[金额])` | `=TSUM("订单表[金额]", "店铺", B2)` | `=SUMIFS(…)` |
| `=INDEX(订单表[金额], 3)` | `=TVALUE("订单表[金额]", 3)` | 同左 |
| `=ROWS(订单表)` | `=TCOUNT("订单表")` | 同左 |
| `=MAX/MIN(订单表[金额])` | `=TMAX/TMIN(…)` | 同左（带条件时导出为 `MAXIFS` / `MINIFS`） |

限制：只转换函数调用的结构，认不出的写法**原样保留**；条件列来自不同的表、参数个数不对时不转换（避免算错）；嵌套在别的函数里的引用只改那一段。

> 为什么引用要写成字符串：Univer 自己的表格引用只能指向单元格区域、在浏览器里逐格计算，做不到下推到服务端。

## 计算方式与注意事项

- **两遍计算**：Univer 逐个等待异步函数，上千个单元格会变成上千次串行请求。平台函数注册为同步函数：第一遍命中缓存的直接返回，未命中的先返回占位文字「计算中…」并登记；本轮结束后把所有未命中的合并成**一次批量请求**（单批最多 5000 个，服务端按条件签名一次扫表），写入缓存后再触发一次重算。所以打开含大量 D / T 公式的工作簿，会先看到「计算中…」再变成数。
- 数据集内容变化（导入、写回、连接同步）后，缓存作废并重算；数据表的筛选 / 切片器变化时自动重算。
- **数据范围受限的用户**：服务端按他的数据范围先过滤再计算，结果只含他能看到的行。
- 公式诊断（「公式」菜单）能列出循环引用并定位到格子，估算大范围公式的计算开销。

## xlsx 兼容

逐个函数的支持情况见 [Excel 函数兼容清单](excel-functions.md)（绝大多数 Excel 函数都支持，含 `XLOOKUP`、`LET`、`LAMBDA`、`VSTACK`、`TEXTSPLIT`、`REGEXTEST` 等新函数）。导入的文件用到不支持的函数时，导入结果会点名是哪几个；公式诊断里 `#NAME?` 的格子会说明是不支持的函数（附原因 / 替代）还是拼错了。

- 导入导出时处理 Excel 的新函数前缀：表格里写的 `XLOOKUP`、`IFS`、`FILTER`、`SORT`、`LET`、`LAMBDA` 等，写入 xlsx 时加 `_xlfn.` / `_xlfn._xlws.` / `_xlpm.` 前缀（Excel 打开才认），读入时去掉，往返不丢失。
- 条件格式（含图标集）、Excel 表格（含汇总行）、行列分组、命名区域会导入导出；暂不支持的内容导入时会提示「未能导入」。
- **没有实现**：VBA 宏（xlsm）、Power Query、外部数据连接；xlsx 里 Excel 原生的数据透视表没有专门处理（Gridlake 的透视表是服务端计算后写成普通工作表，用「透视分析」重新建）。

函数的完整清单以 Univer 当前版本为准；若需要确认某个 Excel 函数是否可用，直接在表格里输入试一下（不认识的会显示 `#NAME?`）。
